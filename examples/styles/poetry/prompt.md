# 流动诗境

让文字成为纸、墨、呼吸与光，用有文学气息但有冲力的排版表达歌词中的情绪和人物关系。以细节清楚的衬线字为骨架，自由交替横排、竖排、局部大字与细小旁白；拉丁文字保留完整单词。诗意不等于慢速漂浮，重心可以快速转移，重要词应在关键时刻落稳、清楚可读。

材料要参与叙事：压力可以挤压纸与文字，打开可以翻折出新的空间，坠落可以带动字形与镜头下沉，抓取可以收拢分离的笔画或单词。让歌词语义决定动作，不把这些例子变成固定特效表。浅纸、深墨和少量灰紫、朱砂、暖光形成有职责的色彩关系，具体选择随新歌改变。

根据真实短语、重音与音乐段落，在快速推拉、掠过镜头、纸折翻转、字形变换与短暂停留之间切换。快歌可以在短语内部多次重新构图。让一条墨线、一张纸或一个字形不断改变角色，通过形体和运动方向自然承接下一段。避免重复居中标题、无意义的慢速平移和全程同样繁忙。底部翻译清楚、稳定、安静，与主视觉保持距离。
