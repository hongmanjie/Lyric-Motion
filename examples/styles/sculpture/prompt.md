# 数字雕塑

把文字与几何当作处在同一空间中的演员。用体积、遮挡、距离、材质和照明表达当前歌词中的关系，让物体的变化具有内容上的理由。

以深色空间、清楚的实体字形、冷暖反射光为创作起点；配色和材料可根据新歌改写。交替安排紧凑的局部、完整物体和开放空间，保留明确的视觉重心与读词时间。节拍推动重量和动作，情绪决定密度与尺度。形体、光线和运动方向应自然接续。

在可靠的短语时间点快速改变距离、视角和尺度，让冲击后有短暂的缓冲与稳定。动作速度来自歌曲，动作理由来自内容；保留形体与运动方向的接续。

避免每句都旋转一个立体单词、无意义粒子背景和过强辉光。底部阅读字幕安静、清楚。演示里的道具、段落结构与时长不需要沿用；为新内容重新构图，也允许与用户方向融合。
