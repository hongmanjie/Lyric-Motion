# 数字雕塑

让三维空间、材质、灯光、镜头与结构演化表演这首歌。先从新歌词寻找动作与关系，再决定哪些形体如何接近、分离、变形或转化。画面的主要表达应来自可见空间和物理关系，文字可以省略，也可以只是物体上的小型刻字、标签或空间中的短语。适合内容时可以使用立体字，它不是每段必备的主体。

用透视、遮挡、前景和远景、视差与相机运动建立深度。形体要有足够尺度，交替考虑空间穿行、材质近景、完整雕塑和开放环境，让观看位置的变化揭示内容。镜面金属、透明玻璃、粗糙表面和轮廓光是可选的材料关系；深色空间、冷光和少量暖色也是起点，具体选择服从新歌。

让物体结构、空间距离、材质和照明的变化具有语义上的原因。根据可靠歌词时间和实际可用的音乐依据组织镜头与动作：快段可以迅速穿越、变向与重构，也可以为舒展段落保留持续移动和停顿。实测能量、能量上升点和已核对的节拍应如实区分；镜头速度、分镜数量和段落时长都由新歌决定。

让轮廓、结构关系、材质接缝、相机轨迹或光的方向承接下一构图，并支持按绝对时间确定性导出。底部歌词字幕安静、清楚，与主要形体保持距离。避免默认巨字顶栏、反复旋转同一个词、每段相同的物体加圆环、过小主体、无意义粒子背景和淹没形体的辉光。为新内容重新设计结构、道具与镜头，不复用演示的固定段落，也允许与用户方向融合。
