# 纸绘叙事

先拆解歌词、构思完整故事，再让连贯的纸绘角色、道具与因果动作演出歌曲；重复歌词推进新的事件和选择。

先读 story-planning.md 和 guide.md，查看 visual-reference.svg。由 Agent 在新工程中先写歌词分析、故事梗概、角色变化、道具去向与分镜事件，再编写动画；用户只提供歌曲、歌词和可选方向。

主角想做什么，什么阻止它，动作带来什么后果，为什么下一幕会发生？每镜既响应当前歌词，也让故事推进。重复歌词应有新的事件、理解或选择，不能重播旧镜头或只换颜色、姿态。

用少量属于当前歌曲的贯穿物建立和回收情绪。保留角色连续、手部接触和物件状态；视线、身体、手与物件有顺序，动作包含预备、发生、反应和阅读停留。景别、方向和道具接力让镜头自然衔接。

可按需使用 story-kit.mjs 的动作阶段、表情过渡、接触坐标和可改写角色骨架；不要固定示例中的角色、道具、场景、色板、镜头数或结局。

使用真实歌曲时长和提供的歌词时间；底部歌词清楚克制。不伪造拍点或均分逐字时间。直接实现，检查全尺寸关键帧及完整连续播放，修正空泛、重复与连续性问题后导出。
