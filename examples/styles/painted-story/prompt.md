# 纸绘叙事

以有性格的纸绘角色、因果动作和场景变化演出歌词。保留笔触与温度，为每首歌重新设计故事。

- 先理解歌词的叙事、情绪转折和视角，再设计角色、关系与场所。
- 一个动作要有动机、预备、发生和反应；角色从头到尾保持可辨认的外形。
- 保持平面绘画质感，让剪辑、视线和动作承担叙事。

- 文字服务于故事；需要底部歌词时，保持可读、克制并给动作留出空间。
- 标题和关键字可以进入场景，但不要每句都套同一种标题卡。

- 近景、全景、主观视角和留白随情绪切换，每个镜头有明确视觉重心。
- 用前后遮挡、景别与色块组织平面空间，避免无意义的伪三维旋转。

- 形体略有弹性；细小线条抖动不能让角色漂移或遮住表演。
- 移动后的物件应继续存在或合理离场，镜头切换延续运动方向和叙事因果。

- 用真实音频、歌词时码和实测声学变化安排镜头；让安静段落有停留、强句有明显动作。

- 把歌词转译成可见事件、人物选择、距离变化或环境变化；不要只给歌词配装饰背景。

- 优先使用视线、运动、物件或画面形状衔接，按歌曲需要选择擦拭、翻页、遮挡或切镜。

- 不要复制参考中的角色、固定镜头表或每首歌复用同一故事。
- 不规定模型、客户端、固定色板、镜头数量、时长或主角；用户明确要求优先。
- 不要把未核验的转写当准确歌词，也不要把等分文字当逐字对齐。

结合本项目真实音频和提供的歌词时间，先形成当前歌曲独有的创作方案，再直接制作、预览、导出并修正。保留原始输入和之前的好版本。示例只说明能力，不是必须套用的成片模板。
