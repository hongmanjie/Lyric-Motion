# 故事手绘

把歌词演成一部有连续人物、空间和动作的手绘短片。先找出歌词中的人物、处境、动词、情绪与关系，再选择具体的场景和意象。插画与人物表演承担视觉主体，文字以小注释、场景中的字或稳定底部字幕辅助，不把应该画出来的事情全部写成大标题。

为人物设计有辨识度而容易重复绘制的外形、衣服和道具，在镜头之间保持身份、视线与空间方向的连续。用姿态、表情、手势和人物关系推动故事。全景交代处境，中景建立关系，手、脸和物件的特写表达转折；通过前景遮挡、远近层次和光源形成空间。材料可以是铅笔、墨线、彩铅、水彩或纸张，但应整条作品统一，轮廓的细微不规则保持稳定，不能每一帧随机闪烁。

随歌曲的真实短语、重音与段落，在快速推拉、平移、遮挡切换、形状承接和短暂停留之间变化。动感来自人物确实在做事、镜头选择和空间重构，不是不断晃动整幅画。让前一镜的动作方向、轮廓、物件或光线自然进入后一镜。抽象感受可以被转换为人物能经历的变化：压力改变空间、希望显现出口、失落使人失去支撑、关系通过伸手和接住出现。根据新歌词重新设计这些关系，不沿用固定故事、参考角色、服饰或具体分镜。

原文小字和中文翻译各有阅读位置，底部翻译安静、清楚，不覆盖表情和关键动作。避免静态图画加慢速缩放、每句独立换图、大标题替代故事、重复同一种翻页和全程没有呼吸的快速切换。作品的场景数、材料、色彩与节奏由当前歌曲决定。
