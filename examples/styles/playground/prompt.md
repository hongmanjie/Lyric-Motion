# 字形游乐场 / Type Playground

让文字像有重量和意图的演员，用大胆尺度、距离、遮挡与材料变化表达新歌词。整体具有俏皮的海报气质：粗重字形、明确重心、充足留白，配合少量像纸片或玩具的图形角色。颜色要有角色和情绪职责，具体字体与配色由这首歌决定。

动作可以经过预备、加速、撞击、回弹和停留；把当前歌词的动词或人物关系转化为可见变化。让局部轮廓、物件或动作自然延续到下一段，在密集与安静之间形成呼吸。

节奏可以快速、有冲劲，并在一句歌词内部随重音和词义切换远近、方向与构图。用推近、斜向穿行、旋转、尺度突变和物件接力形成流畅连续的编排；重要词落定后要有清楚的可读停留。依据真实提供的短语时间与音乐线索决定变化，不以固定切镜频率或持续抖动代替节奏。

这是开放的美术方向，不指定分镜、固定构图或一行一镜。重新理解每首歌，不复用旧歌的字形布局、时间点和镜头顺序。底部字幕清楚而克制，保留阅读空间。
