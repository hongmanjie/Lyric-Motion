# 节奏图形

以歌词词语作为主要画面材料：逐词进入、累积重排、字形与词义动作共同推动整个构图，配合选择性的图形和粒子。

- 每句先找语义动作，再决定字形、图形、镜头与空间关系。
- 强弱有对比：强句快速改变尺度与构图，停顿让观众读懂焦点。
- 同一首歌形成自己的形状语言；动感不等于持续抖动或频闪。

- 需要逐词演出时，让唱到的词进入视觉重心；已出现的词继续缩放、移动、让位或接力，不用无关英文标签替代唱词。
- 关键字可放大、拆分、折叠、聚散或变成空间；字体大小根据语义重要性变化。
- 保持主体字可辨认；副歌词与辅助线条应让位给主体。

- 交替使用极大字形、留白、局部特写和全幅图形；不要连续居中套版。
- 用字形轮廓、线、几何体或插画动作形成一个明确的视觉事件。

- 让词语在同一构图中累积、重排、改变关系；在重点词和语义转折处才推动整页变形或换景。
- 使用自然加减速、预备、回弹和物件接力衔接画面。
- 在真实强音或语义爆发时改变规模、方向或形态；粒子只在部分事件出现。

- 优先使用可靠词级数据；只有行级 LRC 时，可借助真实 ASR 词边界制作明确标注的编辑动效时间，不能宣称已验证逐字对齐。没有词级依据时不要等分句子伪造时间。
- 从真实音频提取能量和声学起音，结合歌词时间安排变化；声学起音不冒充人工核验的拍点。
- 在强句内可有连续动作和次级变化，但要留出阅读与呼吸。

- 词义可以直接改变字形行为：躲对应遮挡、逃对应位移、绕对应路径、接住对应落下与承托；具体实现按新歌词原创。
- 把接住、离开、靠近、躲避、展开等动词变成可见的运动和关系。
- 重新设计当前歌曲的图形隐喻，不固定使用示例中的心形、纸飞机或词语。

- 通过形状变换、方向延续、遮罩、字形碎片或图形接力衔接；避免随机硬切特效。

- 不固定配色、字体、镜头时长或镜头数；不把参考画面逐镜复刻。
- 不要全程撒粒子、每拍缩放或把所有歌词等分成假逐字动画。
- 识别不清的歌词必须标记待确认；可先做语义关键字，不伪造整句字幕。

为当前歌曲重新设计，不固定词语、配色、分镜数量、镜头时长或字形布局。用户方向优先，直接实现并检查全尺寸画面与实际连续播放。

先查看同目录的 visual-reference.svg 并阅读 guide.md。 motion-kit.mjs 提供可按需组合的布局接力、曲线路径、低对比字阵、短时粒子和实测音频响应。主焦点、响应动作和环境层一起设计，不能用角落小字加大片空背景应付整句。
