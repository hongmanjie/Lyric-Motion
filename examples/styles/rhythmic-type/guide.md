# 节奏图形：把词语变成一场空间表演

先查看同目录的 `visual-reference.svg`，再读 `prompt.md` 和 `profile.json`。`motion-kit.mjs` 提供经过示例使用的确定性动效积木。新歌要重新编排，不能只换示例里的几个字。

## 从新歌到画面

1. 使用歌曲真实时长、LRC 行级时间；有可靠词级数据时再设计逐词揭示。只有行级时间时，语义关键词可以做编辑动效，但应与已核验逐字时间分开保存。
2. 为段落选择一种**关系**：追问、承托、挤压、靠近、传递、消散、聚合……先画出关系，再挑字形。每个段落需要发生一件观众看得懂的事。
3. 选一组属于这首歌的材料，例如轨道与球、纸片与折线、窗口与光束。用同一组材料变换关系，形成视觉连续性。不要把示例的球、词语、色板当成必选素材。
4. 把画面分成主焦点、响应动作和低对比环境。主字可占画面高度的 25–60%；环境可以是裁切轮廓字、空间轨道、字阵、阴影或语义图形。安静处保留留白，强句扩大事件范围。不要用均匀撒点填满画面。
5. 让已唱过的词继续让位、转身、变小或变成下一幕的承托物。主词在场、图形有因果，才能兼顾丰富度和阅读。

## 可复用的动作代码

`init --style 2` 会把整个风格包复制到新工程的 `style/`。在工程中按需导入：

```js
import {layoutAt, drawRibbon, cubicPoint, drawBurst, drawEchoes,
        acousticPulse, energyAt} from './style/motion-kit.mjs';
```

- `layoutAt`：用两组作者设计的字形姿态接力，旧词换位，新词入场。每项可有 x、y、size、angle、alpha。
- `cubicPoint` / `drawRibbon`：让字、物体和镜头沿同一条可见路径接力；可以逐渐绘出、变粗、拆断。
- `drawEchoes`：把已出现的词变成低对比字阵，并为主焦点保留排除区域。不要提前显示未唱到的整句。
- `drawBurst`：由绝对时间和固定种子生成短暂纸屑，支持任意顺序 seek；在语义落点和少数强音使用。
- `acousticPulse` / `energyAt`：读取实测能量和起音，用于次级弹性、线宽或镜头强调，不能当成已核验拍点。

需要实测音频时，由 Agent 调用：

```sh
node <toolkit>/tools/analyze-audio.mjs --audio /path/song.mp3 --out /workspace/projects/song/assets/audio-features.json
```

输出不覆写已有文件。它测量 RMS、低频能量和能量上升起音，不提供歌词对齐、BPM 或人工核验拍点。

## 让画面丰富但有重心

同一首歌交替使用全幅字形、斜向排版、局部特写、分区交互和短暂停留。辅助线应指向动作，重复字应来自当前唱词，粒子应有出发点与结束。连续两幕若都是居中大字加空背景，重新设计其中一幕的空间事件。

进入新词时可在约 0.12–0.3 秒完成主要位移，之后安排响应、拖尾、关系变化；这些是试验区间，不是必须固定的节拍。用真实片段播放判断是否抢拍、停空或读不清，再调整。强音可以改变整个布局，而不只是把所有元素放大一点。

## 交付前

检查全尺寸首帧、最长停留、最高密度、关键词落点、转场中间帧和字幕区域。连续播放成片，修正跳闪、主字互相遮挡和只剩角落小字的空段。`check` 证明确定性与可导出；观看记录才说明实际看过哪些动作。保留工程、原始歌词时间和上一版。
