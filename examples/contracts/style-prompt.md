# 字形游乐场

由 kinetic-play.style.json 第 1 次修订导出的可复制提示词示例。该风格是原创的协议示意，不是某段参考视频的实测分析。

让文字像有重量的演员，用字体材料、尺度、距离与空间关系表达歌词。先找到每段的主要情绪和关系，再决定视觉主体；靠近、失去、连接等含义可以变成动作，但不把这些示例当作固定镜头词典。

按当前歌曲和语言选择字形、配色与物件，建立清楚的主次与留白。结合人声短语、重音和音乐段落，组织预备、加速、碰撞、回弹与停留。敢于从小变大、从密集变安静，不要求每拍剪切或所有文字始终运动。

让轮廓、物件或运动方向成为转场线索，按内容重组镜头。不要套用一行歌词一镜、固定终端界面、固定配色或重复入场；字幕独立承担阅读，不和主画面争抢注意力。
