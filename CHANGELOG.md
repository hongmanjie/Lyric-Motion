# Changelog

## 0.1.0-alpha.3 — 2026-10-16

- Added Story Sketch, a fourth optional direction for lyric-led characters and hand-drawn scenes.
- Reworked all four examples with phrase-driven camera changes, semantic action and fluid transitions; public previews use a 14.3-second original instrumental excerpt.
- Added evidence-based video reconstruction prompts, draft validation and portable prompt bundles; transferable style extraction remains a separate workflow.
- Reorganized both READMEs around purpose, installation, first use and a conversational invocation for every feature, with a four-style media gallery.
- Preserved supplied-song comparisons in private projects and refreshed reproducible public media separately.

## 0.1.0-alpha.2 — 2026-10-15

- Added optional Playground, Flowing Poetry and Digital Sculpture creative directions, with automatic free creation as the default.
- Added `styles`, `style --id`, and `init --style`, with numeric/Chinese aliases, portable profile/prompt copies and explicit custom-style priority.
- Added three original example implementations and reproducible public GIF/PNG/MP4 previews. Example scene timing is not a mandatory new-song structure.
- Added transactional same-excerpt preparation for three local style studies using user-provided timed media. Private song comparisons remain outside public releases.
- Included Noto Serif JP with its OFL notice in portable installations.

## 0.1.0-alpha.1 — 2026-10-15

- Separated the private single-song production from the public toolkit.
- Added independent project import with real audio duration and language-neutral LRC/SRT/TXT handling.
- Added self-contained Codex / Claude Code project Skill installation.
- Added reference preparation and reusable style prompt/profile import/export.
- Generalized browser discovery, shared preview, deterministic seeking, MP4 rendering and SRT export.
- Added an original 16-second procedural-score demo and reproducible GIF/PNG/MP4 README media.
- Added English public paths, bilingual READMEs, MIT/third-party notices and allowlisted release packaging.

Known limits: no bundled forced aligner; viewing/listening capabilities depend on the agent; fresh-client discovery and macOS/Linux host execution are not yet verified.
