## 一、为什么需要这个项目？

想用 Agent 制作视频？又不想折腾环境？不想猜测选择何种工具？

**Lyric Motion 为你整理好制作所需的工具、环境准备流程，以及持续更新的视频风格和 Skill。** 直接使用自己的 Codex／Claude Code 对话，就能参考已有风格制作视频，也能让 AI 按你的方向自由创作。

Agent 负责理解歌词、设计分镜与编写动画；项目负责素材导入、歌词时间、预览和本地导出。每首歌保留独立工程，生成后还能继续改。无需另开生成网站、注册项目账号或填写一张复杂的制作表。

## 二、让 Agent 安装

在 Codex 或 Claude Code 中打开准备存放作品的目录，把下面这段发给 Agent：

~~~text
请帮我安装 Lyric Motion。
仓库：https://github.com/hongmanjie/Lyric-Motion.git
安装到当前打开的项目，适配你当前所在的 Codex 或 Claude Code。

将源码获取到独立目录，先阅读 README.md、AGENTS.md 和 docs/install.md。
检查并复用 Node.js 22+、FFmpeg、FFprobe、Chrome／Edge／Chromium。
缺少依赖时，请按当前系统使用可靠的官方来源或包管理器主动补齐，
优先采用不影响其他项目的安装方式；只有确实需要系统权限时再说明原因。
完成项目级 Skill 安装，保留已有 Skill 和作品，遇到冲突不要直接覆盖。
验证安装后的工具、两个风格包和示例渲染，告诉我如何启用并开始第一支 MV。
只有我需要从音频生成歌词时，再按需准备本地识别环境和模型。
~~~

核心工具**无需 npm install、无需额外 API Key**。安装完成后，Codex 使用 $lyric-motion，Claude Code 使用 /lyric-motion；新装后未发现 Skill，可新开对话，或让 Agent 读取它给出的 SKILL.md 路径。[安装与环境说明](docs/install.md)

## 三、快速复刻已有风格

**附上新歌曲和 .lrc 歌词，选择上面喜欢的一种画面语言，直接说：**

> 使用 Lyric Motion 的「纸绘叙事」风格制作这首歌的完整横屏 MV。先拆歌词、构思一个完整故事，主角和道具按这首歌设计。让角色选择和场景事件演出歌词，重复段落继续推进故事。底部加清楚的中文歌词。直接实现，检查画面和连续播放，修正问题后给我 MP4 和可编辑工程。

或者：

> 使用 Lyric Motion 的「节奏图形」风格制作这首歌的完整横屏 MV。让歌词词语依次入场、让位、重排，图形动作表达词义；画面有层次，强句改变构图，粒子适量。直接制作、播放检查并导出。

不用填写字体、镜头数量或技术框架。没有歌词时，可以先说“从这首歌生成 LRC 草稿”。选风格后，Agent 会收到完整风格包：**提示词与美术规则＋原创画面参考＋可选动效代码**，再围绕新歌曲创作；不是只换示例里的几行字。[查看两个风格包](docs/styles.md)

## 四、功能与启用方式

### 1. 生成歌词：歌曲 → LRC 草稿

可以生成标准 **.lrc** 文件（不是 .lyc）。本地 Whisper 识别音频，输出带模型估计时间的 LRC、SRT、文本和原始转写。首次使用由 Agent 准备独立 Python 环境并下载模型，之后复用缓存。**唱词可能漏字或识错，结果保留待校对状态；不是外部歌词强制对齐。**

**这样启用：**

> 用 Lyric Motion 从这首歌生成 LRC 歌词草稿，保留原音频和原始转写，标记需要校对的内容，先不用制作视频。

[识别依赖与校对](docs/lyrics.md)

### 2. 选择风格：歌曲＋歌词＋风格包 → MV

选择 **1「纸绘叙事」** 或 **2「节奏图形」**。Agent 会读取包中的提示词、美术与动作指南、画面参考，节奏图形还带确定性动效积木；导入时一起复制到新工程，方便调整和复用。角色、配色、字形和分镜仍按新歌词设计。纸绘方向会先拆歌词、构思完整故事，再编写镜头事件；重复段落须有新的情节和人物选择。

**这样启用：**

> 用风格 2「节奏图形」做这首歌。颜色暖一点，强句更有冲击，结尾安静一点，其他按风格包完成并导出。

[风格示例与包内容](docs/styles.md)

### 3. 自由创作：歌曲＋歌词＋你的方向 → 原创 MV

不选风格时默认自由创作。用一句话描述情绪或方向即可，Agent 自行决定材料、构图、动作与分镜。

**这样启用：**

> 用这首歌和歌词自由创作一支 MV，俏皮、艺术、炫酷。让文字、图形和构图共同表达内容，动作与音乐段落呼应，最后给我横屏成片和工程。

### 4. 提炼风格：参考视频 → 可复用提示词

提供视频，可指定观察的区域和时段。Agent 观看并拆解字体、材质、构图、动作、转场和歌词联动，交付风格提示词、结构化档案和观察依据。之后可与新歌一起使用。

**这样启用：**

> 只提炼这个视频上半部分的风格，解释动画如何呼应歌词，输出能用于新歌的风格提示词。不要固化成同一套分镜，暂时不用制作成片。

### 5. 参考复刻：参考视频＋新歌曲 → 完整 MV

附上你自己的参考视频、新歌和歌词，Agent 连续完成**观察参考 → 提炼制作方向 → 按新歌词设计动画 → 预览修正 → 导出成片**。参考可以约束画面语言、动作机制和切换力度；新内容按歌曲重新编排。

**这样启用：**

> 参考这个视频的字体、构图和动感，用我上传的新歌和歌词制作一支横屏 MV。关键词出现时画面有符合词义的变化，强句有明显动作。不要停在分析提示词，直接制作、检查连续播放并给我成片。

没有定时歌词时先生成草稿。只有网页链接而无法观察视频时，Agent 会明确说明缺少的参考内容。分析和观看记录会区分实际观察、推测与未确认的部分。[五种工作流](docs/workflows.md)

## 五、项目与贡献

作品保存在独立 projects/，保留原始文件名、输入哈希、歌词时间轴、动画代码和导出文件。完成后交付 MP4、可编辑工程和源码归档；已有交付不会被直接覆盖。预览、字幕、修改和导出是上述创作流程的一部分；普通使用一直通过对话完成。[架构与工具](docs/architecture.md) · [贡献说明](CONTRIBUTING.md) · [更新记录](CHANGELOG.md) · [验收范围](docs/acceptance.md)

工具在本地处理和渲染，Agent 客户端决定哪些内容发送给模型。识别与美术效果取决于素材、模型和实际校对；行级 LRC 不代表逐字对齐，实测声学起音不代表人工核验拍点。技术检查不能代替观看成片。
