# Four directions in twenty seconds

This original highlight combines selected passages from Playground, Flowing Poetry, Digital Sculpture and Story Sketch. It is a concise overview of the toolkit's creative range; complete individual previews remain in `../styles/`.

Regenerate after rendering the four public demonstrations:

```sh
node tools/make-highlight.mjs
```

The output is 1920 × 1080, 30 fps, exactly 600 video frames. Eight-frame transitions are centered on 5, 10 and 15 seconds. The music is one continuous stream using the project's original procedural instrumental: its 16 seconds followed by the first four seconds, with a short final fade. The source-video audio is discarded. No user recording, commercial lyric, translation or reference footage is included.

`demo.gif` is the silent 800-pixel-wide inline preview; `demo.mp4` includes the original instrumental. `poster.png` and the four numbered frames come from the actual encoded highlight. The manifest records source hashes, selected frame ranges, transitions, soundtrack treatment and file sizes.

Frame inspection and continuous-playback coverage are recorded separately. Export verification and an existing audio stream do not establish subjective listening. This instrumental montage does not demonstrate sung-vocal alignment.
