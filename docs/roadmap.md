# Roadmap

## Current alpha: conversations first

- Portable project-level Skill and local toolkit for Codex / Claude Code.
- Independent song projects, actual media probing, LRC/SRT/TXT import.
- Reference evidence preparation, reusable style profile/prompt workflow.
- Video-to-prompt reconstruction with authored analysis, evidence, and an exportable production request.
- Automatic free creation plus four optional, editable art directions: Playground, Flowing Poetry, Digital Sculpture, and Story Sketch.
- Editable code, deterministic preview/render, MP4/SRT and technical checks.
- Original reproducible demo, actual README media and a public release allowlist.

This is an alpha toolkit. The agent does the creative work; it is not a one-button generator or model service. Client discovery and cross-platform host testing remain documented verification work.

## Next priorities

1. Verify actual discovery and invocation in fresh Codex and Claude Code sessions, then document exact tested client versions.
2. Exercise macOS/Linux, Unicode edge cases, mixed-language lyrics, long tracks and interrupted exports.
3. Add an optional alignment adapter with explicit provider/resource/cost choices; keep TXT honest until real timing is available.
4. Add independent vocal and reference-to-new-song examples using redistributable materials.
5. Improve revision manifests and a narrowly scoped retry/cancel workflow from real failures.

A file-upload workbench, custom chat UI, model backend, hosted accounts and billing are outside the first release. Reconsider them only after the conversation workflow has demonstrated demand.
