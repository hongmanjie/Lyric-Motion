# Reference + new song → finished MV

The requested deliverable is a finished new video. Reference analysis is an internal stage; do not stop after a prompt unless the user requested analysis only.

1. Resolve the actual reference, requested region/range, new audio and lyric file. Preserve source inputs. For a webpage link, use available browser tools to observe the actual video; metadata/cover images do not prove animation style. If playback is inaccessible, say what is unavailable and request only the missing source while continuing independent song preparation.
2. Follow reference.md to prepare evidence, inspect full-size frames and watch continuous playback. Record visual/audio/lyric coverage and uncertainty. Identify focal hierarchy, material, motion mechanisms, cadence, semantic relationships and useful transitions.
3. Author a portable style-profile.json and style-prompt.md. Keep useful observed relationships without copying source characters or forcing the new song into incompatible shot times. For a detailed reconstruction request, reverse-prompt.md can additionally preserve the observed sequence with evidence.
4. Obtain timed lyrics. Use supplied LRC/SRT; otherwise follow lyrics.md for an actual transcription draft and resolve important uncertain words. Never fabricate token times from evenly split text.
5. Import the new song with --style-profile and --style-prompt; optionally --reference for an independent local source copy. Custom material replaces built-in preferences as a unit.
6. Continue create.md: design the current song's scenes, implement original artwork, preview, check and render. No new user approval is required for routine composition choices already delegated.
7. Watch encoded playback, correct visible issues, then return MP4, editable project, captions if requested, and concise provenance/review limitations.

The source video can guide composition, typography and energy. New lyric meanings determine visible actions and musical changes determine emphasis. Referencing a style does not authorize uploading the original source, private songs or full lyric files to a public repository.
